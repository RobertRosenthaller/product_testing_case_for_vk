# «Без заграна» — прототип для Яндекс Путешествий

Кликабельный мобильный веб-прототип нового раздела: зарубежные города, куда можно полететь по внутреннему паспорту РФ всей компанией, без пересадок за границей.

На телефоне занимает весь экран, на компьютере открывается в рамке смартфона. Сборка не нужна: это статический сайт на HTML, CSS и JS без зависимостей.

## Структура

```
frontend/
├── index.html            точка входа
├── css/styles.css        стили и токены дизайна
├── js/config.js          адрес бэкенда (пусто = локальные демо-данные)
├── js/data.js            демо-данные: города, рейсы, жильё, фото
├── js/api.js             слой данных: локально или через бэкенд
├── js/app.js             экраны, навигация, календарь, шторки
└── assets/img/           иконки категорий, баннер, фото «Выходных»
```

## Сценарий

Главная → плитка «Без заграна» (или «Найти жильё или билет» → круглая вкладка «Без заграна») → даты и участники → «Найти» → Ереван, Алматы или Минск → «Как добраться» (2 прямых рейса) или «Где остановиться» (2 варианта жилья) → назад к подборке.

Логика фильтра на 7–11 декабря 2026: свободно 3 места на рейсах в Алматы, 4 в Ереван и 8 в Минск. Для троих доступны все три города, для четверых Ереван и Минск. Для девяти выдача пустая и предлагает ближайшие даты, когда места есть на всех. На другие даты число мест (от 2 до 9) генерируется из дат, поэтому меняется вместе с ними.

## Автопроход

Кнопка «Смотреть сценарий» (справа от телефона на компьютере или внизу главной на телефоне) показывает весь путь за минуту: подсвечивает шаги стеклянной рамкой и нажимает сама. Остановить можно кнопкой «Стоп», клавишей Esc или «Сбросить демо» (оно возвращает прототип к исходным параметрам и не запускает автопроход).

## Деплой на GitHub Pages

1. Создайте на GitHub публичный репозиторий, например `bez-zagrana`.
2. Загрузите в корень репозитория содержимое папки `frontend` (сам `index.html` должен лежать в корне, а не в подпапке). Через сайт: Add file → Upload files → перетащите файлы и папки → Commit changes.
3. Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт будет доступен по адресу `https://<ваш-логин>.github.io/bez-zagrana/`.

Через терминал:

```bash
cd frontend
git init && git add . && git commit -m "Прототип «Без заграна»"
git branch -M main
git remote add origin https://github.com/<ваш-логин>/bez-zagrana.git
git push -u origin main
```

Файл `.nojekyll` уже лежит в папке, чтобы GitHub Pages отдавал файлы как есть.

## Локальный запуск

```bash
cd frontend && python3 -m http.server 8000
# открыть http://localhost:8000
```

## Данные и фото

Цены, рейсы, отели и наличие мест демонстрационные. Фото городов и жилья подгружаются с Wikimedia Commons по прямым ссылкам, авторы перечислены в приложении (кнопка «Фото: Wikimedia Commons» внизу главной). Иконки категорий и баннер взяты со скриншотов приложения для демонстрации концепта.
